## 3. Generate Changelog

`cliff.toml` is configured with conventional commit parsing:

```bash
git-cliff --tag v0.1.0 -o CHANGELOG.md
```

Produces a categorized changelog (Features, Bug Fixes, Testing, etc.) from all merged PRs.

## 4. Tag and Release

```bash
git tag -a v0.1.0 -m "v0.1.0 — MVP Core Engine"
git push origin v0.1.0
```

Then create a **GitHub Release** from the tag. Attach:
- The generated CHANGELOG section
- Pre-built binaries (optional — `bin/persatrix-server`, `bin/orch`)
- Docker image references
