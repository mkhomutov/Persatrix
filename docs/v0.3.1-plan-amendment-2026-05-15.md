# v0.3.1 plan amendment — 2026-05-15 — RFC 0034 Conversational Working Memory

> Status: amendment to [v0.3.1-plan.md](v0.3.1-plan.md). Driver:
> [ISSUE-0052](issues/ISSUE-0052-persona-conversational-working-memory-gap.md).
> RFC: [0034 — Persona Conversational Working Memory](rfcs/0034-persona-conversational-working-memory.md).

## Context

A regression-debug session against the `ember-owl` persona surfaced a
load-bearing defect: the persona's LLM call carries only the current
event in the `messages` array — no in-progress conversation transcript.
Within two turns the persona contradicts the user's stated context,
cannot answer `"what was your question?"`, and cannot resolve
referential follow-ups (`"I like it"`). Self-contained statements still
survive (the fact tier extracts them turn-locally), which is why the
defect was not caught by the existing memory legs of
[MT-MEMORY-005](manual-tests/MT-MEMORY-005-dementia-test.md). Full
diagnosis: [ISSUE-0052](issues/ISSUE-0052-persona-conversational-working-memory-gap.md).

## Decision

[RFC 0034](rfcs/0034-persona-conversational-working-memory.md) is
absorbed into v0.3.1, **Phase 1 only** (DM channels). Phases 2–3
(group-channel role mapping, instrumentation/tuning) remain v0.3.x. The
user-facing v0.3.1 story is amended from *"memory works"* to *"memory
works — long-term *and* in-conversation"*: the persona will both
remember stated facts across interactions (RFC 0026) and follow the
conversation it is currently having (RFC 0034).

## Why v0.3.1 and not a v0.3.1.1 patch

RFC 0026's release-acceptance
([MT-MEMORY-005](manual-tests/MT-MEMORY-005-dementia-test.md)) silently
undercounts without RFC 0034: the referential-follow-up legs cannot
pass when the fact-extraction model cannot see the prior turn that
supplies the referent. Shipping RFC 0026 without RFC 0034 would publish
a memory-quality story that fails on the same demo it ships to
validate. The two RFCs share an acceptance surface and must ship
together.

## Why RFC 0034 does not delay v0.3.1

Phase 1 is DM-only, has no cross-RFC implementation dependency on RFC
0026 (only a shared release-acceptance dependency), and merges in
parallel under the same umbrella. The only sequencing constraint is
[RFC 0034 OQ #1](rfcs/0034-persona-conversational-working-memory.md#open-questions)
(per-session vs. per-channel transcript window), which is gated *before*
the RFC 0034 PR plan opens implementation PRs.
