### 3.1 Required Upgrade Notes in Changelog

This is the canonical source for Upgrade Notes text.

| Notable change | Detail |
|----------------|--------|
| **[Behaviour change — cost gate]** Wallet lease before every LLM call | Every LLM call now acquires a server-issued lease from `WalletService` before issuing. Five origins wired (workflow task / chat / autonomous TICK / sub-agent / channel-message reply). A wallet denial surfaces as `reply_status="error"` on chat (HTTP 200 with `LeaseDenied.message` — closing the v0.2.3 chat-bypass known limitation) and `idle_reason=budget_denied` on autonomous TICK; workflow tasks fail with `error_type=budget_exceeded`. See [RFC 0023 §F](rfcs/0023-llm-call-leasing.md#f-failure-modes). |
| New `wallet:` block in `config/optimization.yaml` | Top-level, sibling of `cost:`. Keys: `ttl_seconds` (default `60`, = 2× the 30 s per-call timeout, [OQ §2](rfcs/0023-llm-call-leasing.md#open-questions)), `reaper_interval_seconds` (default `5`), `max_active_leases` (default `16`, per-agent DoS ceiling). Absent block / key falls back to defaults; no operator action required. |
| New `BudgetExceededError` failure surface | The Python `WalletClient` raises it on `LeaseDenied`. Chat re-surfaces it as `reply_status="error"` carrying `LeaseDenied.message`; autonomous TICK short-circuits to `DO_NOTHING` with `agent.persona.tick.idle{idle_reason="budget_denied"}`; workflow tasks fail with `error_type=budget_exceeded`. |
| `MemoryFacade` → `MemoryStore` rename (Phase 1 facade freeze) | `agents.memory.MemoryFacade` preserved as an alias for **one minor version** (deprecation removal in v0.3.3 per [RFC 0029 §Phased Implementation Plan](rfcs/0029-personal-society-storage-split.md#phased-implementation-plan)); new code imports `MemoryStore`. Society-tier methods raise `SocietyBackendUnavailable` — single-agent mode never opens Postgres. |
| New direct-`aiosqlite` import lint rule | `import aiosqlite` outside `agents/memory/` fails CI. Direct `EpisodicMemory` / `RelationshipMemory` / `NotesStore` construction emits a `DeprecationWarning`; route through `MemoryStore` so the v0.4.0 personal/society backend swap stays a single-call-site change. |
| `tiktoken` promoted to a hard runtime dep | RFC 0023 [OQ #5](rfcs/0023-llm-call-leasing.md#open-questions) — the `accurate-tokens` extra is removed; builds depending on it must drop the extra from their install command. No operator action required (the `cl100k_base` count is what `LLMClient` already used). |
| Wallet lease log shape (RFC 0023 PR 7 finalisation) | `wallet: lease granted` / `wallet: lease finalized` (`op=settle` or `op=release`) / `wallet: lease reaped — settled at granted amount on TTL expiry` events carry a stable field set ([#391](https://github.com/mkhomutov/Persatrix/pull/391)) — `lease_id`, `workflow_id`, `agent_id`, `model`, `cause`, plus settlement-time `op` / `actual_input_tokens` / `actual_output_tokens`. Downstream log consumers can pin field names. See [observability.md § 10.7](observability.md#107-wallet-lease-lifecycle-rfc-0023). |
