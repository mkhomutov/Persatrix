[v0.3.0 plan Master Progress Overview row 4](v0.3.0-plan.md#master-progress-overview) lists RFC 0008 PR 6 as the last outstanding implementation PR (5/6 merged). The closeout PR absorbs review follow-ups from PRs 1–5 and flips the RFC to `✅ Implemented`.

The original PR plan attached a "30-day calibration window" to PR 6, framed as a hard gate before the RFC could close. That framing is being walked back in this PR (see [RFC 0008 OQ #12 walkback](#rfc-0008-oq-12-walkback) below) — the project has no production workload yet, so a calendar-driven soak window is not load-bearing. Calibration of the eviction parameters is rescheduled as a v0.3.x follow-up that fires whenever production-like data exists, not a v0.3.0 release blocker.

Implications:

1. **PR 0 (this document) opens immediately** — Phase 3 fires when the final Phase 2 workstream crosses ≥75% PRs merged.
2. **PR 1 (MT execution report) opens once RFC 0008 PR 6 lands** — no calendar dependency; PR 6 is just the next normal closeout PR.
3. **`docs/rfcs/0008-calibration-review.md`** is updated by RFC 0008 PR 6 from "must complete before flip" to a forward-looking placeholder for a v0.3.x calibration carve-out (per the OQ #12 walkback).

### RFC 0008 OQ #12 walkback

[RFC 0008 §Open Question 12](rfcs/0008-agent-memory-context-optimization.md#12-memory-eviction-parameter-calibration--ship-defaults-with-mandatory-metrics-collection) originally read "30-day calibration review … is a documentation commitment, not a code gate" (this PR removes that phrasing from mitigation #3 along with the rest of the calendar-window framing). The PR plan and `0008-calibration-review.md` then escalated it into a hard pre-flip gate. This PR resolves the inconsistency by editing the gate language:

- [`docs/rfcs/0008-agent-memory-context-optimization.md`](rfcs/0008-agent-memory-context-optimization.md) §OQ #12 — keep the metrics commitment (mandatory per-eviction instrumentation) and drop the calendar-window phrasing; calibration is rescheduled to v0.3.x once a production-like workload exists.
- [`docs/rfcs/0008-pr-plan.md`](rfcs/0008-pr-plan.md) PR 6 — drop the "calibration window closes 2026-05-29" / "30-day calibration timer" language; PR 6 is a normal closeout (review-follow-up absorption + RFC status flip).
- [`docs/rfcs/0008-calibration-review.md`](rfcs/0008-calibration-review.md) — convert from "Gate: this review must complete before RFC 0008 flips to `✅ Implemented`" to a v0.3.x forward-looking placeholder that fires when real-workload telemetry is available.
- [`docs/v0.3.0-plan.md`](v0.3.0-plan.md) Master Progress Overview row 4 — drop the "gated on 2026-05-29" qualifier.

The instrumentation work shipped in PR 5 is unchanged; only the calendar gating is removed.
