- **Upgrade Notes** must call out, at minimum:
  - **[Behaviour change — cost gate]** Every LLM call now acquires a server-issued lease before issuing. Five origins wired (workflow task / chat / autonomous TICK / sub-agent / channel-message reply); a wallet outage surfaces as `reply_status="error"` on chat and `idle_reason=budget_denied` on TICK ([RFC 0023 §F](rfcs/0023-llm-call-leasing.md#f-failure-modes)). Closes the v0.2.3 chat-bypass known limitation.
  - **New `wallet:` block in `config/optimization.yaml`** (top-level, sibling of `cost:`). Keys: `ttl_seconds` (default `60`, = 2× the 30 s per-call timeout, OQ §2), `reaper_interval_seconds` (default `5`), `max_active_leases` (default `16`, per-agent DoS ceiling). Absent block / key → defaults; no operator action required.
  - **New `BudgetExceededError` failure surface** — `WalletClient` raises it on `LeaseDenied`; chat re-surfaces as `reply_status="error"` carrying `LeaseDenied.message`; autonomous TICK short-circuits to idle.
  - **`MemoryFacade` → `MemoryStore` rename (Phase 1 facade freeze)** — `agents.memory.MemoryFacade` preserved as an alias for one minor version (deprecation removal in v0.3.3 per [RFC 0029 §Phased Implementation Plan](rfcs/0029-personal-society-storage-split.md#phased-implementation-plan)); new code imports `MemoryStore`. Society-tier methods raise `SocietyBackendUnavailable` — single-agent mode never opens Postgres.
  - **New direct-`aiosqlite` import lint rule** — `import aiosqlite` outside `agents/memory/` fails CI. Direct `EpisodicMemory` / `RelationshipMemory` construction emits a `DeprecationWarning`; route through `MemoryStore`.
  - **`tiktoken` promoted to a hard runtime dep** (RFC 0023 [OQ #5](rfcs/0023-llm-call-leasing.md#open-questions)) — the `accurate-tokens` extra is removed; builds depending on it must drop the extra from their install command.
  - **Wallet lease log shape (RFC 0023 PR 7 finalisation)** — `lease_acquire` / `lease_settle` / `lease_reap` events carry a stable field set ([#391](https://github.com/mkhomutov/Persatrix/pull/391)); downstream log consumers can pin field names.

Acceptance:

- `make all` builds at `0.3.2`.
- `CHANGELOG.md` contains a curated `[0.3.2]` section with the Upgrade Notes above.
- All prior version sections untouched (`git diff` against `main` for lines below the new section shows zero diff).
