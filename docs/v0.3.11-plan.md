# v0.3.11 Plan — Conversations That Run Themselves (autonomous agent-only channels)

**Status**: 📋 Planned
**Target version**: v0.3.11 (the *human-out-of-the-loop* rung — a roster convenes itself, discusses, converges, and synthesizes with no human present; the capstone of the v0.3.x realism arc, extending the [usefulness ladder](v0.3.x-sequencing.md#the-usefulness-ladder) at the brainstorm rung)
**Created**: 2026-06-28
**Branch prefix**: `feature/v0311-`
**Target**: `main`
**Merge strategy**: Squash merge per [BRANCHING.md](BRANCHING.md)
**Codename**: *Conversations that run themselves* (continues the *Conversations …* arc through v0.3.7–0.3.10)

**Goal**: orchestrate v0.3.11 end-to-end. One user-facing story: **give a roster of personas a topic and watch them discuss it, converge, and produce a readable synthesis — with no human in the loop — and watch the flagship demo run it across four vendors at once (Anthropic + OpenAI + Gemini + watsonx.ai).** No human seeds the topic, no human keeps it alive, no human ends it; the discussion still converges, terminates, and always leaves a readable artifact. This is the honest proof that the v0.3.7→v0.3.10 realism work stands on its own once the human is removed — and the single best adoption demo the project can ship before v0.4.0 (organizations).

> **What is opt-in vs. untouched:** autonomous behaviour is **opt-in per channel** (`autonomous.enabled: true`), and an autonomous channel **cannot be created without an enforced cost cap** (`validate` rejects it otherwise). **Ordinary human channels are byte-for-byte untouched** — the anti-collapse counter-pressure is scoped strictly to `autonomous.enabled` channels ([OQ #2 resolution](#scope-decisions-locked-at-plan-authoring-time-2026-06-28)), so the bias-to-silence defaults the realism arc installed stay exactly as shipped. v0.3.11 is purely additive — nothing changes for an existing channel until an operator marks one autonomous.

Two workstreams, one release contract:

- **RFC 0052 — Autonomous Agent-Only Channels (the headline + the substantive feature RFC).** A channel that self-convenes a roster on a topic and runs a human-free brainstorm that converges, terminates, and synthesizes. **Assembly of shipped seams (channels / governance / scheduling / reasoning) plus four new pieces** ([RFC 0052 §B–§E](rfcs/0052-autonomous-agent-channels.md#design--implementation)): self-convening (assembled from the publish path) and three mechanisms that each *extend a shipped governance invariant* — anti-collapse cadence, a mandatory cost cap with a reserved synthesis allowance + deterministic bounded close, and a standing-schedule aggregate bound + timer-wiring seam. Owned by the [RFC 0052 PR plan](rfcs/0052-pr-plan.md).
- **RFC 0053 — Gemini + watsonx.ai providers (the cross-vendor enabler; bundled, independently shippable).** Two first-class providers added through the [RFC 0033 §H](rfcs/0033-model-alias-layer.md#h-multi-provider-extensibility) seam (one class + one factory branch + priced aliases each). Its motivating consumer is the RFC 0052 [Phase 4](rfcs/0052-autonomous-agent-channels.md#phase-4-flagship-demo) four-vendor demo. Owned by the [RFC 0053 PR plan](rfcs/0053-pr-plan.md).

Same thin-orchestration shape as [v0.3.10-plan.md](v0.3.10-plan.md): the RFC PR plans own the internals; **this doc owns which phases, in what order, by what release gate**, and locks the version-scope decisions.

## Scope decisions locked at plan-authoring time (2026-06-28)

These were resolved with the maintainer at plan opening (the [v0.3.x-sequencing Amendment 2026-06-28](v0.3.x-sequencing.md#amendment-2026-06-28--add-the-autonomous-agent-only-channel-as-the-v03x-realism-capstone) left the integer and the load-bearing OQs to plan-opening time):

- **v0.3.11 anchors on RFC 0052 + 0053; RFC 0039 → v0.3.12 candidate.** The amendment named two parallel candidates without locking the integer. Since the maintainer's driver is conversation realism, the autonomous-channel rung takes v0.3.11; [RFC 0039](rfcs/0039-user-accounts-authentication.md) (accounts/auth — "safe remote console") is a *different* user story (deployment safety) and stays the parallel v0.3.12 candidate. Bundling it would obscure what the user gained.
- **RFC 0052 ships all four phases (full capstone).** Phase 1 convene + bounded brainstorm + mandatory cap → Phase 2 anti-collapse cadence → Phase 3 standing/scheduled + aggregate bound → Phase 4 flagship demo. One rung, one patch — consistent with every prior realism rung (v0.3.7–0.3.10).
- **RFC 0053 is bundled but cuttable.** RFC 0052 and 0053 are independently shippable (RFC 0052 runs on any single provider). The default lands both in v0.3.11; **if a provider SDK proves fiddly, the four-vendor headline slips a point release** and the demo ships offline/two-vendor — the rung is not held hostage to two brand-new vendor SDKs ([§Risk](#risk-and-mitigations)).
- **RFC 0044 Phase 1 rides as a cuttable fold-in safety net.** Autonomous = no human to catch a bad conversation, so the [golden-trace eval harness](rfcs/0044-eval-set-golden-traces.md) matters more here than anywhere prior — but it carries no competing user story, so it rides as infrastructure (the way RFC 0045 rode v0.3.10) and is droppable without touching the headline.

**RFC open-question resolutions locked here** (full detail in the RFC OQ §Status notes + the [0052](rfcs/0052-pr-plan.md#open-question-resolutions-locked-at-plan-authoring-time) / [0053](rfcs/0053-pr-plan.md#open-question-resolutions-locked-at-plan-authoring-time) PR plans; two ⚠️ *reverse* the RFC's own lean):

| 0052 #1 convener | **distinct `convener` role** | ⚠️ reverses "lean chair = convener" — convener owns the agenda lifecycle (open + advance), chair keeps its shipped close role; the §C ration lives on the convener path |

- **Changing human-channel defaults** — anti-collapse is `autonomous.enabled`-scoped; bias-to-silence stays exactly as shipped for human channels.
- **Org roles / authority / clearance** — RFC 0012 (v0.4.0); an autonomous channel is a flat roster. **External bridges** — RFC 0011 external (v0.5.0); autonomous channels are internal.
- **Standing topic *queue*** + a **runtime `RegisterTimer` API** beyond the config-round-trip seam — Phase 3 follow-ups ([RFC 0052 OQ #4](rfcs/0052-autonomous-agent-channels.md#open-questions)). **An exhaustive provider sweep** — RFC 0053 adds exactly Gemini + watsonx; others follow the §H recipe later.

## Why this plan exists

Unlike v0.3.10 (one feature RFC), v0.3.11 carries **two RFCs** — the headline (RFC 0052) and a bundled enabler (RFC 0053). The umbrella earns its place:

1. **A patch needs a release contract, not just a PR sequence.** v0.3.11's promise — the human-free converge-and-synthesize — is a release-level gate no single PR owns; the acceptance bar is the *combined* manual-test outcome (`MT-AUTONOMOUS-001` + the no-runaway and close-by-budget legs), not any one RFC's unit suite.
2. **The headline and the enabler can decouple.** RFC 0053 is bundled but independently shippable; this doc owns the call that if a provider SDK drags, the rung still ships and the four-vendor headline slips a point release ([§Risk](#risk-and-mitigations)).
3. **The fold-in and OQ-deviation decisions are release-level** — whether RFC 0044 P1 rides along, and the two OQ resolutions that reverse the RFCs' leans (distinct convener; meter the summary), are version-scope calls this plan locks and the RFC OQ sections record.

## Acceptance for v0.3.11

The release ships when **all** hold:

- **`MT-AUTONOMOUS-001` passes live** — a channel marked `autonomous.enabled` convenes itself on a topic, the roster discusses it with **zero human turns**, converges, terminates, and emits a readable synthesis; spend ≤ the mandatory cap.
- **The no-runaway leg holds** — under an adversarial "everyone wants to talk" roster, turns and tokens stay bounded by `max_rounds` + the interaction cap + the per-agenda-item escalation ration; no unbounded loop.
- **The close-by-budget leg holds** — on a budget-exhausted close, **both** artifacts are still produced — the chair synthesis turn *and* a real RFC 0020 summary **per persona** (not the `[interaction summary unavailable]` placeholder) — proving the **roster-scaled** synthesis reserve is honoured now that the summaries are metered to the interaction ([OQ #6 resolution](#scope-decisions-locked-at-plan-authoring-time-2026-06-28)).
- **`MT-AUTONOMOUS-002` passes (anti-collapse)** — a roster that would collapse to silence under the default bias instead works through a multi-item agenda under autonomous pressure, *and the convener never advances twice into silence on the same agenda item* (the per-item loop guard).
- **`MT-AUTONOMOUS-003` passes (standing/scheduled)** — a standing channel convenes a fresh interaction on schedule across a window, unattended, *and stops at the aggregate bound* (`max_convenings` / standing cost budget).
- **`validate` rejects unsafe autonomy** — an `autonomous.enabled` channel without `interaction_budget_tokens` is rejected; a standing channel without an aggregate bound is rejected.
- **CLI + web both surface the feature** — an operator can create/edit an `autonomous` channel *and* trigger **convene** from the `persatrix channel config`/`convene` CLI **and** the web Channel-settings panel (not only config-as-code YAML); the block round-trips through the RFC 0050 REST PATCH/GET.
- **The cross-vendor headline runs live, OR is documented as slipped** — `MT-AUTONOMOUS-MULTIPROVIDER-001` (Anthropic + OpenAI + Gemini + watsonx.ai brainstorm, no human, all four keyed, spend ≤ the interaction cap) + the `MT-PROVIDER-GEMINI/WATSONX-001` smokes pass live; **if RFC 0053 slipped**, the demo ships offline/two-vendor and the four-vendor MT tracks into v0.3.12. The offline `make demo-autonomous` runs with zero keys regardless.
- **Docs + diagrams are edited, not just verified** — the guides (channels / persona-agents / model-providers / web-console) and the `workflow-execution` + `system-overview` diagrams are updated in the feature PRs ([0052](rfcs/0052-pr-plan.md#documentation--diagrams) / [0053](rfcs/0053-pr-plan.md#documentation--diagrams) docs sections) and verified at release-prep.
- **The full gate sweep is green live on host** — Go `-race -cover`, the Python persona/channel/wallet suites, Vitest, Rust, ruff/mypy/clippy/go-vet; `make validate`; the live-provider Docker smoke; the `MIT ← BUSL ← Private` gate.

## Phase 1 — Implement RFC 0052 + RFC 0053

Owned end-to-end by the two RFC PR plans. The release gates this plan enforces over them:

- **The mandatory cost cap is a Phase-1 acceptance gate, not a later hardening.** `validate` must reject `autonomous.enabled` without `interaction_budget_tokens` from the first PR — uncapped autonomy never reaches `main`.
- **The roster-scaled synthesis reserve lands with the close path.** Because OQ #6 meters the autonomous-close summary, the reserve must cover the chair synthesis turn *and* per-persona summaries; the close-by-budget acceptance leg ships in the same PR as the bounded close, never after it.
- **Anti-collapse stays autonomous-scoped.** The convener per-agenda-item ration is gated by `autonomous.enabled`; the PR that lands it carries the human-channel regression proving the shipped CE5 one-escalation guard is unchanged off the autonomous path.
- **RFC 0053 is cuttable.** If a provider SDK drags, the four-vendor demo degrades to offline/two-vendor and the headline MT tracks into v0.3.12 — without holding RFC 0052 or the tag.
- **RFC 0044 P1 and the demo polish are cuttable** — if the release stretches, drop them without touching the autonomous-channel headline.

## Risk and mitigations

| Risk | Mitigation |
|------|------------|
| An unattended channel runs away on cost with no human to stop it. | The per-interaction `interaction_budget_tokens` cap is **mandatory** (`validate` rejects autonomy without it) and server-side fail-closed in the wallet; `max_rounds` is a second independent bound; a standing channel adds a mandatory **aggregate** bound. The no-runaway acceptance leg measures turns + spend against the cap. |
| The fail-closed cap swallows the closing artifact. | The **roster-scaled** synthesis reserve (OQ #6: summary now metered) holds back a lease for the chair synthesis turn *and* per-persona summaries; the close-by-budget acceptance leg asserts both artifacts survive a budget-exhausted close. |
| Anti-collapse re-introduces the pile-on the realism arc removed. | Scoped strictly to `autonomous.enabled` (OQ #2); human channels keep the shipped bias-to-silence + CE5 guard. The landing PR carries a human-channel regression. |
| Distinct convener (OQ #1) adds a role the RFC didn't assume. | Recorded in the RFC OQ §Status + the [0052 PR plan](rfcs/0052-pr-plan.md); convener owns agenda lifecycle, chair keeps its shipped role — additive, no human-channel change. |
| CLI/web surface work is under-scoped (the RFC's Files-Touched omitted `web/`). | Corrected: the [0052 PR plan](rfcs/0052-pr-plan.md) dedicates PR 2 to config surfaces + PR 3's legs to the convene action, per the RFC 0050/0051 operator-editable precedent. |
| Two new vendor SDKs (RFC 0053) drag the release. | Independently shippable; if a provider drags, RFC 0052 ships with the offline/two-vendor demo and the four-vendor headline + MT slip to v0.3.12 — the tag is not held. |
| "Discuss autonomously" reads as a v0.4.0 decision feature. | Explicit scope line: this is the **brainstorm** rung (discuss → converge → synthesize); the decision-reaching version is RFC 0028 (v0.4.x). The org substrate (RFC 0037/0038) is untouched. |
