## Overview

Every design decision lives in the [scope locks](v0.3.16-scope-locks.md) or the issue each PR cites; this file states, per PR, the branch, the scope, the failing test that goes first, the acceptance line and the migration (always **none** this release). Sequencing, acceptance for the release, the live arc and the ROADMAP hygiene stay in the master plan. Review findings are recorded in the PR body and, when deferred, as issues ([review-process.md](methodology/review-process.md#where-findings-are-recorded)).

### Why these are one workstream set

Five workstreams, one release: D unblocks A and E structurally; A is the headline; B makes A's decisions (and two older ones) readable; C gives the org train its regression bar. None shares a store or a migration — they meet only at the release.

Design: [ISSUE-0143](issues/ISSUE-0143-debt-sweep-26-files-at-size-cap.md) and lock 4. Pure structural PRs: no behaviour change, the full suite byte-identical, each under 500 changed lines — which means one at-cap file per PR, since a split moves half of it.

**Scope**: split `agents/persona_runtime/memory_context.py` (500/500) at a real seam — the candidate is the tier-recall half versus the assembly-and-inject half, named for what each holds. **Tests**: none new; every existing test passes unchanged and the eval goldens replay byte-identically. **Acceptance**: both files under cap with headroom for A1's roster move and A2's gate input. **Migration**: none.

### PR D2 — `feature/v0316-debt-close-path`
**Scope**: split `agents/persona_runtime/close_path.py` (500/500) so the E1 test has a home. **Tests**: as D1. **Acceptance**: under cap; the `store_episode` call inside `with record_write_scopes(interaction)` is unmoved, and the binding itself stays where it has been since #851 — `record_write_scope.py`, not this file (review F-1). **Migration**: none.

## Workstream A — the audience gate

Design: [ISSUE-0132](issues/ISSUE-0132-memory-egress-gate-blind-to-room-audience.md) and locks 1–3; the RFC 0037 amendment A2 writes becomes the canonical statement.

### PR A1 — `feature/v0316-issue0132-roster-split`
**Scope**: the dormant rail. `HttpChannelRosterFetcher.fetch` splits into a members half and a directory half so a directory `401` no longer discards the members; roster resolution moves ahead of the §D gate in `_inject_memory_context` and runs for every channel-anchored turn, DMs included — on a DM turn the roster is resolved **for the gate only** and no roster section is injected (review F-4). The gate does not change; the group-roster prompt text does not change. **Tests** (first, failing): a directory miss still yields members; a DM event resolves a roster and the working memory gains no roster section; the roster injection for a group event is byte-identical before and after the move. **Acceptance**: the gate has a roster to read on every channel turn and no prompt changed. **Migration**: none.

### PR A2 — `feature/v0316-issue0132-audience-shadow`
**Scope**: the RFC 0037 amendment (separate file: §D gains the AND-condition, §E's terminal-withhold composition, §G's cause vocabulary); `TurnInjectionGate.filter_entries` takes the audience input and records the four verdicts (*admit*, *withhold-disjoint*, *withhold-unknown-fetch-failed*, *withhold-unknown-no-provenance*); a `memory.egress.audience: shadow | live | off` knob mirroring `memory.facts.cross_room`, default `shadow`; the per-turn source-room cache; the shadow log; the eval driver's in-process roster seam and the audience seed (`EVAL-MEMORY-005`: DM-taught fact, one room with Bob, one without) recorded offline; `shadow_measurement` gains the lock-1 criteria, the admit/withhold delta among them (review F-2); **MT-PERSONA-CONFIDENTIALITY-001 Leg 5** authored self-contained — its own DM teach and interaction close before the ask (review F-3) — with the vacuity rule and both auth-mode runs. **Tests** (first, failing): the three-case regression (a room adding anyone not in the DM, Bob or a peer persona → *withhold-disjoint*; a room whose every member was in the DM → *admit*; a DM with Bob alone → *withhold-disjoint*); the fetch count equals the distinct-source-room count (review F-6); *unknown* splits by cause; NULL `source_channel_id` never acquires an audience; `public` is exempt; the §G watch sees an audience withhold with its cause; in shadow the entry is recorded and still admitted, in live it is withheld; §E serves no projection for it. **Acceptance**: every prompt byte-identical in shadow; the verdict renders. **Migration**: none.

### PR A3 — `feature/v0316-issue0132-audience-live` *(verdict-gated)*
**Scope**: the default flips to `live` with withhold-disjoint / admit-unknown; `EVAL-MEMORY-005` re-recorded offline under the flip, `001`–`004` untouched and byte-identical; ISSUE-0132 resolved; the release-note trade written. **Opens only on a green verdict**, before release-prep PR 0. **Tests**: the same regression under the live default; a shadow-pinned replay of the new golden must miss the cassette (the strip test that made EVAL-MEMORY-003 load-bearing). **Migration**: none.

### PR E1 — `feature/v0316-issue0137-explicit-principal`

The relationship-tier "ambient-only, and stated" sentence rides B1, which touches that tier anyway. **Migration**: none.
