# v0.3.10 Plan — Conversations Worth Posting Into (reasoning before posting)

**Status**: 📋 Planned
**Target version**: v0.3.10 (the *worth-posting-into* rung — considered posts + semantic silence on top of the v0.3.8 brainstorm; extends the [usefulness ladder](v0.3.x-sequencing.md#the-usefulness-ladder) inside the v0.3.x realism arc)
**Created**: 2026-06-23
**Branch prefix**: `feature/v0310-`
**Target**: `main`
**Merge strategy**: Squash merge per [BRANCHING.md](BRANCHING.md)
**Codename**: *Conversations worth posting into* (continues the *Conversations …* arc after v0.3.7 *worth watching*, v0.3.8 *that converge*, v0.3.9 *you can mine*)

**Goal**: orchestrate v0.3.10 end-to-end. One user-facing story: **personas think before they speak — they privately decide whether a turn is worth a post and what it should add, so a group conversation reads as considered rather than reflexive, with fewer pile-on turns and no eager "I agree" noise.** A persona that has nothing to add stays silent *with a reason*; a persona that does post composes under a private plan (what to add, whom to address, what not to restate). This is post quality and silence quality raised at the same seam — the natural next rung after "conversations that converge."

> **What ships active-by-default vs. opt-in:** the go-live flip ([PR 6](rfcs/0051-pr-plan.md)) sets newly governed channels to `mode: bid` — **semantic silence** (the no-pile-on half) is the out-of-the-box behaviour. The **considered, plan-threaded compose** (`mode: plan`) is a one-rung-up, **per-channel operator opt-in** ([RFC OQ-2](rfcs/0051-reasoning-before-posting.md#open-questions)), and the reflexion loop (`revise ≥ 1`) is a further opt-in on top of that. So v0.3.10 delivers the *silence* half of the headline by default and the *considered-posts* half on a deliberate, one-flip opt-in (both live-tunable, no restart). The acceptance E2E exercises `mode: plan` explicitly for that reason.

One workstream, one release contract:

- **RFC 0051 — Reasoning Before Posting (the headline + the only feature RFC).** A private, per-turn deliberation that generalizes the shipped [RFC 0030](rfcs/0030-multi-agent-conversation-governance.md) Tier-B salience bid from a scalar `speak/score` into a structured `{ should_post, plan }` verdict. `should_post=false` ends the turn in `DO_NOTHING` *before* the expensive compose (semantic silence, a net saving on pile-on); `should_post=true` threads a private `CompositionPlan` into the existing compose. Reuses the leased `fast`-model seam (metered against the same `interaction_id`; idle stays free); the trace is walled (never a message, never the channel store, never a peer's RFC 0034 working memory) and audit-only. A default-`off`-until-governed per-channel `reasoning` knob rides the RFC 0050 config surface. Owned by the [RFC 0051 PR plan](rfcs/0051-pr-plan.md) (Phase 1 deliverable). Per [RFC 0051 §B–§G](rfcs/0051-reasoning-before-posting.md#design--implementation).

Same thin-orchestration shape as [v0.3.9-plan.md](v0.3.9-plan.md): the RFC PR plan owns the internals; **this doc owns which phases, in what order, by what release gate**, and locks the version-scope decisions (which RFC phases ship, which defer).

**Scope decisions locked at plan-authoring time (2026-06-23):**

- **RFC 0051 ships Phases 1–3 + Phase 5 in v0.3.10; Phase 4 is deferred.** Phases 1–2 land **dark** (gated behind `reasoning.mode`, default `off` = byte-for-byte today's score gate); Phase 3 lands the config knob + telemetry + the `off → bid` go-live flip; Phase 5 lands the committed reflexion loop, feature-toggled off (`revise: 0`). **[Phase 4](rfcs/0051-reasoning-before-posting.md#phase-4-optional--follow-on-native-extended-thinking-depth) (native extended-thinking `depth: deep`) is OUT** — it needs a provider-protocol change *and* is telemetry-gated on [RFC 0051 OQ 1](rfcs/0051-reasoning-before-posting.md#open-questions), which can only be evaluated *after* Phase 3 telemetry exists. `validate` rejects `depth: deep` as an unbacked enum value until it is built.
- **RFC 0051 is the sole headline; RFC 0039 stays parallel (→ v0.3.11 candidate).** v0.3.10 is a single tight reasoning release, honouring the [ROADMAP §Version Map](../ROADMAP.md#version-map) one-user-story-per-release contract. [RFC 0039](rfcs/0039-user-accounts-authentication.md) (accounts/auth — "safe remote console") is a *different* user story (deployment safety, not conversation quality); it keeps developing on its parallel near-term track ([v0.3.x-sequencing §Amendment 2026-06-23](v0.3.x-sequencing.md#amendment-2026-06-23--add-v0310-reasoning-before-posting-as-the-next-realism-rung)) and becomes the v0.3.11 candidate. Bundling it would obscure what the user gained.
- **The OQ 6(a) operator reasoning-reveal panel is IN, as its own cuttable PR.** A debug-toggled web-console reveal of the private `reason_note` (you cannot tune the plan-generation prompt without seeing plans). It is net-new UI + a backend debug-egress path, **not** a `ChannelSettings` row, and is droppable without affecting the headline ([RFC 0051 OQ 6](rfcs/0051-reasoning-before-posting.md#open-questions)).

**Candidate fold-ins (maintainer decision — invisible ride-alongs, no headline of their own):**

- **RFC 0045 (open-core policy + CI gate).** License-boundary + dependency-direction CI gate; **no code movement, no user-facing story** ([RFC 0045](rfcs/0045-open-core-extraction-policy.md), target `v0.3.x`). Because it carries no headline it can ride v0.3.10 as infrastructure without competing for the story. Cut without penalty if it would stretch the release.
- **RFC 0034 Phase 3 (working-memory instrumentation/tuning + cache LRU bound).** Tagged `v0.3.x (Phase 3)`, still outstanding ([RFC 0034](rfcs/0034-persona-conversational-working-memory.md)). Synergistic: RFC 0051 leans directly on the RFC 0034 transcript and the salience seam, so closing P3 in the same release is natural.
- **RFC 0008 OQ #12 (eviction-parameter calibration)** — only if the "observed-workload telemetry exists" trigger is now satisfied; otherwise leave deferred.

**Out of scope** — explicitly deferred so they don't pressure the reasoning cut:

- **RFC 0051 Phase 4 (`depth: deep`)** — provider-protocol change + OQ-1 telemetry trigger (above).
- **An end-user "watch them think" surface** — any future end-user reasoning reveal is a *separate explicit egress*, never a relaxation of the [RFC 0051 §E](rfcs/0051-reasoning-before-posting.md#e-privacy-boundary--the-trace-is-walled) wall ([OQ 6(b)](rfcs/0051-reasoning-before-posting.md#open-questions)).
- **A durable reasoning store / persistent trace for offline eval** — the trace is ephemeral + audit-only; a retention-bounded eval sink is a possible follow-on, not v0.3.10.
- **Group deliberation toward a decision** — reasoning *across* personas toward a justified recommendation is [RFC 0028](rfcs/0028-agent-decision-policy-engine.md) (v0.4.x); this RFC is per-persona, per-turn, private.
- **RFC 0039 accounts/auth** — parallel track, v0.3.11 candidate (above).

## Why this plan exists

Unlike v0.3.9 (two RFCs in a hard dependency chain), v0.3.10 has **one feature RFC**. The umbrella still earns its place:

1. **A patch release needs a release contract, not just a PR sequence.** Per [ROADMAP §Version Map](../ROADMAP.md#version-map), a version is defined by what a user *can do*; v0.3.10's promise — "personas think before they speak, so the conversation reads as considered" — is a release-level gate no single PR owns. The acceptance bar is the *combined* manual-test + E2E outcome (`MT-REASON-001` plus a measurable pile-on-suppression delta), not RFC 0051's unit suite.

2. **The go-live is a sequenced, gated flip, not a merge.** RFC 0051 Phases 1–2 ship **dark**; the feature only becomes live when [Phase 3 PR 6](rfcs/0051-pr-plan.md#pr-sequence) flips the governed-channel default `off → bid` in lockstep with the kill switch and telemetry. This doc owns the gate: dark phases may merge freely, but the flip waits on the watch-dogs, and the release tag waits on the flip having run live.

3. **The fold-in and parallel-track decisions are release-level, not RFC-level.** Whether RFC 0045 / RFC 0034 P3 ride along, and that RFC 0039 stays parallel rather than bundling, are version-scope calls the [v0.3.x-sequencing amendment](v0.3.x-sequencing.md#amendment-2026-06-23--add-v0310-reasoning-before-posting-as-the-next-realism-rung) ratifies and this plan executes.

## Acceptance for v0.3.10

The release ships when **all** hold:

- **`MT-REASON-001` passes live** — a persona stays silent *with a stated reason* on a directed-elsewhere / already-answered turn (reason observed via the operator-debug **agent log**, which is what the MT reads per [RFC §E](rfcs/0051-reasoning-before-posting.md#e-privacy-boundary--the-trace-is-walled), not the count-only audit; the PR 7 web-console reveal is an *additional* surface, not a prerequisite for this gate — so PR 7 stays genuinely cuttable), and posts a plan-shaped contribution on a turn it can add to; the private plan is absent from every other participant's view and from the channel transcript.
- **The privacy wall holds** — the no-leak integration test is green for the plan *and* a discarded reflexion draft: zero `messages` rows, zero appearance in a second persona's reconstructed `messages`.
- **The go-live flip has run live** — a newly `salience_gated` channel defaults to `mode: bid`; a 3-persona `mode: plan` brainstorm shows a **countable** pile-on-suppression delta vs. the `off` baseline (suppress-rate by `reason_code`), and the deliberation-latency histogram + budget-starvation + parse-failure counters emit.
- **The kill switch is one flip** — setting a channel to `reasoning.mode: off` restores byte-for-byte today's score-gate behaviour at runtime, no restart.
- **`depth: deep` and `revise ≥ 1` (pre-toggle) are rejected at `validate`** — capability-gated, no silent downgrade.
- **The full gate sweep is green live on host** — Go `-race -cover`, the Python persona + deliberation suites, Vitest, Rust, ruff/mypy/clippy/go-vet; `make validate`; the live-provider Docker smoke.

## Risk and mitigations

| Risk | Mitigation |
|------|------------|
| The score-gate supersession goes live before its kill switch / telemetry. | Phases 1–2 ship **dark**; the `off → bid` flip is coupled to the kill switch + telemetry in RFC 0051 PR 6, and the tag waits on the flip running live. |
| Private-reasoning leakage. | Structural wall ([RFC 0051 §E](rfcs/0051-reasoning-before-posting.md#e-privacy-boundary--the-trace-is-walled)); no-leak test is a release acceptance gate, extended to a discarded reflexion draft. |
| Net-negative-cost is an empirical claim. | RFC 0051 PR 6 cost-delta counterfactual (`mode: bid` shadow arm) proves/refutes it; it does not gate the ship, only the §F claim. |
| Single-feature release feels thin. | The headline is a visible realism lever (fewer pile-on turns, considered posts) continuing the *Conversations …* arc; the optional fold-ins (RFC 0045 / 0034 P3) add substance without a competing story. |
| Bundling RFC 0039 would muddy the story / slip the headline. | Kept parallel → v0.3.11; the sequencing amendment records the call. |
| Reflexion (Phase 5) bloats the release. | Default `revise: 0` (single-pass norm), capability-gated, fail-soft; it is the opt-in quality knob, not the headline — cuttable to v0.3.11 if PR 8–9 slip. |
