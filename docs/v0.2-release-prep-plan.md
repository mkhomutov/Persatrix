### PR 1 — Split `agents/persona_runtime.py`

**Status**: ✅ Merged — PR #95  
**Branch**: `feature/v02-release-prep-split-persona-runtime`  
**Depends on**: nothing  
**Estimated delta**: ~0 net lines (refactor only)

> **Prior extraction context.** `persona_runtime.py`'s module docstring (lines 8–14) records an earlier extraction: type definitions live in [agents/persona_types.py](../agents/persona_types.py), behavior rendering in [agents/persona_behavior.py](../agents/persona_behavior.py), event dispatch in [agents/dispatch.py](../agents/dispatch.py), and tick scheduling in [agents/tick.py](../agents/tick.py). What remains in `persona_runtime.py` is the `_LLMPersonaAgent` class — memory context assembly, the multi-turn tool loop, state persistence, and memory lifecycle. This PR splits _that_ class, not responsibilities already extracted elsewhere.

#### Scope

| File | Change |
|------|--------|
| `agents/persona_runtime/` (new package dir) | Replace the single ~979-line module with a package |
| `agents/persona_runtime/__init__.py` | Re-export `_LLMPersonaAgent` and any other symbols currently imported as `from persatrix_agents.persona_runtime import …` |
| `agents/persona_runtime/memory_context.py` | Memory injection + context-window assembly helpers (episodic recall, relationship summary, working-memory truncation) |
| `agents/persona_runtime/action_loop.py` | Multi-turn tool-use loop driving LLM calls until `stop_reason == "end_turn"` or `max_llm_calls` is hit |
| `agents/persona_runtime/state_persistence.py` | `_persist_persona_state`, `_load_persona_state`, `initialize_memory`, `close_memory` |

#### PR checklist

- [ ] All existing import paths resolve unchanged (verify via `git grep -n "from persatrix_agents.persona_runtime"` and `git grep -n "from agents.persona_runtime"` — no dangling references)
- [ ] No new module duplicates responsibilities already in `dispatch.py`, `tick.py`, `persona_types.py`, or `persona_behavior.py`
- [ ] `make test-python` passes
- [ ] `make lint` clean (ruff + mypy)
- [ ] No file in the new package exceeds 500 lines

## How to Update This Plan

When a PR merges:
1. Set its **Progress Overview** row: Status → `✅ Merged`, add PR number and date.
2. Set the **Status** line in the PR's own section to `✅ Merged — PR #NNN (YYYY-MM-DD)`.
3. Add the PR to the merged-PR table in [ROADMAP.md](../ROADMAP.md) per [Status Hygiene rules](development-workflow.md#status-hygiene).
4. Tick satisfied items in **Acceptance Checklist** above.

When tagging:
5. Flip this document's header status to `✅ Complete — tagged v0.2.0`.
