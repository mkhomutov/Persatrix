**Target version**: v0.3.11 (Conversations that run themselves — the human-out-of-the-loop capstone of the v0.3.x realism arc: [RFC 0052 autonomous agent-only channels](rfcs/0052-autonomous-agent-channels.md), all four phases, with [RFC 0053 Gemini + watsonx.ai](rfcs/0053-gemini-watsonx-providers.md) enabling the four-vendor headline)

**Scope**: the release-prep workstream for the v0.3.11 surface — **conversations that run themselves**. Two implemented headline RFCs, with three invisible fold-ins riding along:

1. **The headline — autonomous agent-only channels** ([RFC 0052](rfcs/0052-autonomous-agent-channels.md), Phases 1–4, ✅ Implemented). An operator arms a group channel (`autonomous.enabled` + a **mandatory** per-interaction cost cap + a mandatory escalation chair, group-only), convenes it once from CLI/REST/web (or on a standing schedule under a mandatory **aggregate** bound), and the roster runs a **human-free brainstorm**: the convener opens, the governed wake chain carries the discussion, the anti-collapse convener cadence works a multi-item agenda without re-introducing pile-on, a productive round **continues** past its replies ([ISSUE-0110](issues/ISSUE-0110-autonomous-productive-round-continuation-stall.md) fixed + live-verified, [#759](https://github.com/mkhomutov/Persatrix/pull/759)), and the discussion **terminates deterministically** (`max_rounds` or the wallet soft budget) with a goal-directed chair synthesis plus one metered RFC 0020 summary per persona — the `1 + N` reserve funds the close even at budget exhaustion.
2. **The enabler — Gemini + watsonx.ai providers** ([RFC 0053](rfcs/0053-gemini-watsonx-providers.md), ✅ Implemented). Two native first-class providers through the RFC 0033 §H seam, completing the four-cloud roster (Anthropic + OpenAI + Gemini + watsonx) the flagship four-vendor brainstorm pins by per-seat alias.
3. **(fold-in) RFC 0044 P1 — golden-trace eval harness** ([RFC 0044](rfcs/0044-eval-set-golden-traces.md)): assertion format + replay LLM client + runner + two seeds (`EVAL-MEMORY-001`, `EVAL-WORKING-001`). Infrastructure, report-only — no CI gate this release.
4. **(fold-in) RFC 0048 console UX rework** ([#760](https://github.com/mkhomutov/Persatrix/pull/760), [#761](https://github.com/mkhomutov/Persatrix/pull/761)): the app-shell redesign (sidebar rail / conversation column / management rail). Behaviour-preserving — the 310-test suite passes unmodified.
5. **(fold-in) memory determinism sweep** ([#739](https://github.com/mkhomutov/Persatrix/pull/739)–[#747](https://github.com/mkhomutov/Persatrix/pull/747)): rowid/trust-score tiebreaks, incl. the latent FIFO-cap oldest-rows-survive bug (#746).

It covers: **execution** of the four already-authored autonomous manual tests plus the two provider smokes (live, real providers, real spend) and the offline demo smoke; the [ISSUE-0109](issues/ISSUE-0109-rfc0052-autonomous-defaults-calibration.md) calibration observations recorded per run; a documentation refresh + a new release checklist; version bump `0.3.10` → `0.3.11`; dating the curated `[0.3.11]` changelog; and final pre-tag verification.

**The release gate is the live autonomous arc, not a migration.** v0.3.11 advances no store (channel store stays v10; persona-memory untouched). The pre-tag gate is the master plan's [Phase 3](v0.3.11-plan.md#phase-3--v0311-release-prep-execution) live sweep: `MT-AUTONOMOUS-001` (convene → converge → terminate → synthesize, zero human turns, spend ≤ cap, both close artifacts), the no-runaway and close-by-budget postures, `MT-AUTONOMOUS-MULTIPROVIDER-001` across all four vendors, and the offline `make demo-autonomous` smoke.

**Out of scope**: new feature work. Deferred — Known Gaps in the release notes, not release gates:

- **ISSUE-0109 defaults calibration** → **post-soak follow-up**. PR 1 *records* the calibration data (rounds-to-convergence, close trigger, reserve headroom, per-convening spend); tuning is a post-tag PR.
- **RFC 0052 §E hardening residuals** → tracked follow-ups: the aggregate convening/spend bounds are per-process (restart resets), the wallet per-convening residue is not yet evicted (`EvictInteraction` uncalled), the two-openers idle race.
- **RFC 0044 PR 4b** (event-asserting seeds) + **EVAL-RECALL-001** → **v0.4.0**, gated on RFC 0041 typed events / a per-interaction-session recipe extension.
- **RFC 0048 remaining scope** → the RFC stays `partially_implemented`; the rework shipped is UX-only.
- **[ISSUE-0105](issues/ISSUE-0105-stale-cli-interaction-budget-not-enforced-warning.md)** (low, stale CLI warning), **[ISSUE-0107](issues/ISSUE-0107-recall-channel-id-narrowing-not-canonicalized.md)**, **[ISSUE-0108](issues/ISSUE-0108-reasoning-reason-note-no-operator-egress.md)** (low, `reason_note` egress) → unslated; **[ISSUE-0106](issues/ISSUE-0106-recall-epoch-filter-decoupled-from-unpersisted-publish-epoch.md)** (medium) → **flag for explicit slotting** (v0.3.12/v0.4.x — maintainer call at PR 2).
- **RFC 0041 typed events** (v0.4.0 train, PRs [#754](https://github.com/mkhomutov/Persatrix/pull/754)/[#755](https://github.com/mkhomutov/Persatrix/pull/755) draft) → **must not merge before the v0.3.11 tag**.
- **RFC 0039 accounts/auth** → v0.3.12 candidate (parallel track).

### Version state

All version-carrying components are at `0.3.10` — bump to `0.3.11` via [`bump_version.py`](../scripts/bump_version.py): `agents/pyproject.toml`, `agents/observability/{metrics,tracing}.py` (`_DEFAULT_SERVICE_VERSION` + the tracing docstring restatement), `cli/Cargo.toml` (+ `cargo update --workspace` for the lock), `internal/server/ui_handlers.go` (`defaultServiceVersion`). `web/package.json` stays `0.0.0` by design.

### Schema / migration state

**v0.3.11 advances no store.** The channel store stays at **v10** ([`sqlite_schema.go`](../internal/channels/sqlite_schema.go)) — RFC 0052 is config + router + wallet runtime state (deliberately no new store migration; the per-process aggregate bounds are the documented consequence) — and the persona-memory store is untouched (the determinism sweep changed ordering, not schema). **No migration release gate.** PR 4 confirms a pre-v0.3.11 store opens as a no-op.

### Wire-compatibility state

v0.3.11 adds **four additive protobuf fields** to `ChannelMessageEvent` ([`proto/task.proto`](../proto/task.proto)): `convene = 27`, `close_notification_redelivery = 28`, `close_notification_close_trigger = 29`, `synthesis_turn = 30`. All additive — a mixed-version deployment degrades to pre-v0.3.11 behaviour on each. **Upgrade-ordering caution for autonomous adopters** (already in the `[0.3.11]` Upgrade Notes' spirit; PR 3 reconciles): the convene/synthesis dispatches carry synthetic `orchestrator:*` sender ids that **pre-v0.3.11 agents reject** at inbound validation ([#730](https://github.com/mkhomutov/Persatrix/pull/730)) — so *arming a channel* requires orchestrator **and** agents at v0.3.11. Ordinary channels are unaffected by skew in either direction; autonomy is opt-in. The `make proto && git diff --exit-code` gate (PR 4) verifies stub sync.

### Manual test state

All release-gating MTs are **authored**; live execution is this workstream (PR 1):

- **[MT-AUTONOMOUS-001](manual-tests/MT-AUTONOMOUS-001.md)** — one-shot brainstorm: arm (safety gates re-proven) → convene → converge → terminate → synthesize, zero human turns, spend ≤ cap, every persona's real summary, re-convene. **The headline gate.**
- **[MT-AUTONOMOUS-002](manual-tests/MT-AUTONOMOUS-002.md)** — anti-collapse cadence: a collapse-prone roster worked through a multi-item agenda; human path unchanged.
- **[MT-AUTONOMOUS-003](manual-tests/MT-AUTONOMOUS-003.md)** — standing/scheduled convening; stops at the aggregate bound (429); wallet footprint recorded (residue residual documented, not asserted).
- **[MT-AUTONOMOUS-MULTIPROVIDER-001](manual-tests/MT-AUTONOMOUS-MULTIPROVIDER-001.md)** — the four-vendor headline, all four vendors keyed; per-seat `gen_ai.system` routing; single shared cap.
- **[MT-PROVIDER-GEMINI-001](manual-tests/MT-PROVIDER-GEMINI-001.md)** / **[MT-PROVIDER-WATSONX-001](manual-tests/MT-PROVIDER-WATSONX-001.md)** — single-provider cloud smokes (watsonx incl. the `project_id` fail-closed check).

**Already live-verified during implementation** (PR 1 formalizes into the report, not first-runs): the offline `make demo-autonomous` arc (boot-verified 2026-07-11), and a **full live Anthropic arc** (2026-07-20, the ISSUE-0110 fix verification): open → productive rounds → cascade-cap structural close → chair synthesis → closed, ~2 min, zero human turns.

**Live-run calibration guidance** (from the 2026-07-20 live runs; feeds [ISSUE-0109](issues/ISSUE-0109-rfc0052-autonomous-defaults-calibration.md)):

- **Openers must NAME the personas.** Bias-to-silence mutes autonomous rounds on bare openers; topics a persona's memory claims were covered draw `nothing_to_add` (convener advance texts get stored as facts → self-reinforcing silence). Convene topics/agendas that address members by name reliably engage them.
- **The global `max_cascade_depth` (5) binds before `max_rounds`** — ≈4 productive rounds per discussion regardless of a higher `max_rounds`. Record which bound actually closes each run.
- Per run, record: rounds-to-convergence vs `max_rounds`, close trigger (`structural` vs `cost`), reserve headroom used (chair turn + per-persona summary tokens vs the `1 + N` hold-back), and — standing — per-convening spend.
- Demo-env gotchas: restart agents **after** the orchestrator (registry wipes on orchestrator restart); machine-pace a whole MT arc in one script rather than idling mid-arc.

The carried-forward v0.3.10 surface (reasoning-before-posting, recall, governance, cost-attribution gates) regression-checks against the RC tip — autonomy is scoped to `autonomous.enabled`, and human channels are pinned byte-for-byte by regression tests throughout the RFC 0052 cluster.
