The bundled second story: **[RFC 0039 Phases 1–2](rfcs/0039-user-accounts-authentication.md)** verified accounts — opt-in behind `auth.mode: enabled`; the shipped default stays `disabled`. Rider: the recall `epoch_id` body override is gone and 4xx-rejected (ISSUE-0106(b)).

### 3.1 Required Upgrade Notes

| Notable change | Detail |
|----------------|--------|
| **[Automatic migrations — two stores]** | Channel store v10 → **v11** (per-channel `classification`) and persona-memory to **v16** (`protection_level` + provenance columns) — both automatic, in-transaction, backfilling **`internal`** (RFC 0037 §C's conservative default). **Downgrade caution**: a migrated store refuses to open under an older binary. |
| **[One-shot, act before upgrading]** notes-backfill level | Notes carry no channel provenance, so v16 backfills **every** pre-migration note `internal` — including notes authored in `restricted`/`secret` turns. Operators with sensitive histories set `PERSATRIX_NOTES_BACKFILL_PROTECTION_LEVEL=<level>` on the **first** run that migrates each persona's `memory.db` (ISSUE-0115(a) / §C's promised flag). It is honoured only at the moment the notes column is created — **inert afterward** (WARN'd and ignored), so the choice cannot be revisited without manual SQL; an out-of-vocabulary value fails the migration loudly rather than falling back. Applies to the notes tier only; episodes and facts keep the `internal` backfill. |
| **[Behaviour — the headline]** cross-room recall is live | A persona now recalls consolidated knowledge across every room it belongs to (room-first-ranked raw experience; cross-room L2 facts), egress-gated by classification. Operators classify rooms `restricted`/`secret` to constrain it (per-channel `classification`; DMs stamp from `dm_default_classification`, default `internal`); reclassify by re-applying config. Absent classification resolves `internal` — nothing becomes `public` by default. |
| **[New opt-in capability]** verified accounts | `auth.mode` defaults to **`disabled`** (byte-for-byte no-delta). Under `enabled`: bootstrap the first operator **before** enabling (`account bootstrap`, 12-char floor); `enabled` beyond localhost **requires HTTPS** (the `__Host-` cookie is dropped on plain-HTTP non-loopback — the console login loops); the agent-attributable REST ingress **stays open** ([ISSUE-0117](issues/ISSUE-0117-agent-ingress-close-knob.md), WARN'd at startup on a non-loopback bind). |
| **[Deliberate break]** recall `epoch_id` body override | The recall endpoint now **4xx-rejects** a body `epoch_id` override (ISSUE-0106(b) — silent acceptance implied isolation that did not exist). No known callers outside tests; external tooling sending it breaks. |
| **[Wire — additive]** one `ChannelMessageEvent` field | `classification = 31` (the §A stamp). Skew degrades conservatively both directions: absent → `internal` on a v0.3.12 receiver; a pre-v0.3.12 receiver ignores it. |
| **[Dependencies]** | New direct deps: Go `golang.org/x/term` (BSD-3), Rust `rpassword` 7 (Apache-2.0). No new Python runtime deps. Compose stacks now pass `--accounts-db /var/lib/persatrix/accounts.db` (the binary's cwd-relative default is not writable in the container). |
