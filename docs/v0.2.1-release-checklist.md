### 3.1 Required Upgrade Notes in Changelog

| Breaking / notable change | Detail |
|---------------------------|--------|
| New gRPC RPC `SendChatMessage` in `AgentService` | Agents must implement `SendChatMessage` or the chat endpoint returns 500. Existing task-only agents are unaffected. |
| New REST endpoint `POST /api/v1/agents/{id}/chat` | Added to the orchestrator REST API; not a breaking change but new callers should handle 404 (agent not found) and 400 (message too long). |
| Binary rename: `orch` → `persatrix` | The Rust CLI binary is now `persatrix`. Update any scripts or aliases that called `orch`. |
| `RelationshipMemory` key schema | Relationship records are now keyed on participant pairs rather than raw agent IDs; the SQLite schema migration runs automatically on first boot. |

## 6. Known Gaps to Document in Release Notes

These items remain intentionally incomplete and should be described as deferred scope, not regressions.

### Chat-specific gaps (v0.2.1 scope limits, RFC 0016 §"What does not ship")

| Area | Description | Deferred to |
|------|-------------|-------------|
| Multi-user support | Single `UserParticipant` per session; no concurrent user isolation | v0.3.0 (RFC 0011) |
| Authentication | Sessions are local, caller-supplied `user_id`; no auth tokens | v0.3.0 (RFC 0009) |
| Streaming responses | Synchronous request-response only; no SSE or WebSocket streaming | Future RFC |
| Agent-initiated messages | No notification infrastructure for outbound agent messages | Future RFC |
| Channel routing for user messages | Chat bypasses channel infrastructure; channels not yet user-ready | v0.3.0 (RFC 0011) |
| Rate limiting for chat | No per-user rate limit on the chat endpoint | v0.3.0 (RFC 0009) |
| Cost tracking for chat | `POST /api/v1/agents/{id}/chat` calls are not counted in `/api/v1/cost/summary` | v0.3.0 follow-up |

### Carried forward from v0.2.0

| Area | Path | Release-note callout |
|------|------|----------------------|
| Resilience | `internal/resilience/` | Stub package; circuit-breaker and dead-letter behavior remain deferred |
| Agent-to-agent protocol | `internal/a2a/` | Distributed cross-node agent protocol deferred |
| Mesh runtime | `internal/mesh/` | Multi-node deployment deferred to v0.3.0 |
| Internal bridges | `internal/bridges/` | Bridge infrastructure not user-ready |
| Internal channels | `internal/channels/` | Shared-channel conversations do not ship |
| Security hardening | `internal/security/` | RFC 0009 follow-on work for v0.3.0+ |
| Telemetry | `internal/telemetry/` | OTEL package is still a stub |
| Budget-exceed abort (`MT-COST-002`) | Live workflow abort on budget exhaustion | v0.2.1 follow-up |
