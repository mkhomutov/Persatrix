### PR 4 — Author Manual Tests: Chat & Participant Surface

**Branch**: `feature/v021-release-prep-mt-chat`  
**Depends on**: nothing  
**Estimated delta**: ~400 lines (4 new test documents + index update)

#### Scope

New manual test documents following the existing template ([docs/templates/MANUAL_TEST_TEMPLATE.md](templates/MANUAL_TEST_TEMPLATE.md)):

| Test ID | Title | Surface |
|---------|-------|---------|
| `MT-CHAT-001` | Chat REST endpoint: send message, receive reply | REST API (`POST /api/v1/agents/{id}/chat`) |
| `MT-CHAT-002` | `persatrix chat` CLI interactive session | CLI REPL |
| `MT-CHAT-003` | Chat session continuity: messages persist across agent restart | Memory persistence |
| `MT-CHAT-004` | User-agent relationship: trust score evolves after chat exchanges | Relationship memory |

Index update:

| File | Change |
|------|--------|
| `docs/manual-tests/README.md` | Add "Chat" section with MT-CHAT-001 through MT-CHAT-004 |

#### Test design notes

- **MT-CHAT-001**: POST to `/api/v1/agents/{id}/chat` with a simple message; verify response shape (`reply`, `session_id`, `agent_display_name`, `reply_status`); verify message length limit (>4000 chars rejected); verify unknown agent returns 404.
- **MT-CHAT-002**: Start stack, run `persatrix chat <agent_id>`, send 2–3 messages, verify replies print, verify `exit` or Ctrl+C exits cleanly.
- **MT-CHAT-003**: Chat with agent, stop agent, restart agent, resume chat with same `--user` — verify episodic memory contains the pre-restart conversation.
- **MT-CHAT-004**: Chat 5+ exchanges with an agent, then use the memory test scripts to verify trust score is non-zero and interaction count matches.

#### PR checklist

- [ ] Each test has Prerequisites, Steps, Expected Results, and Results Table
- [ ] Test IDs follow `MT-CHAT-NNN` pattern
- [ ] Tests are executable without an API key where possible (REST shape tests)
- [ ] Tests that require an API key are clearly marked
- [ ] Index (`docs/manual-tests/README.md`) updated

## Risk Register

| Risk | Impact | Mitigation |
|------|--------|------------|
| Chat tests require live LLM API key | Some MT-CHAT tests cannot run without `ANTHROPIC_API_KEY` | Design REST shape tests that work without API key; mark LLM-dependent steps clearly |
| Version bump breaks Cargo.lock | CLI may fail to build | Run `cargo update --workspace` and `make all` in the version bump PR |
| Changelog generation overwrites curated content | Loss of v0.2.0 release notes | Use `--prepend` mode; manually verify after generation |
| Existing manual tests regress | False confidence in release readiness | Re-run all 13 existing tests, not just the 4 new ones |
