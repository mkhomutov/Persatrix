All eight implementation PRs are merged — workstream **A** (the derived and relayed writes, PRs A1–A4b), **B** (the replayed write, B1–B2) and **C** (the fleet, C1) — so `main` is a usable RC tip. Which PR landed what is in the [release baseline](v0.3.15-release-baseline.md#issue-roll-up) and, per PR, in the [master plan](v0.3.15-plan.md#master-progress-overview) and [residuals PR plan](issues/ISSUE-0082-residuals-pr-plan.md).

This document owns the prep sequencing: **live execution** of the extended [MT-MEMORY-GROUP-TENANT-001](manual-tests/MT-MEMORY-GROUP-TENANT-001.md); a docs verification pass + a new release checklist; version bump `0.3.14` → `0.3.15`; CHANGELOG `[0.3.15]` curation + dating; and final pre-tag verification.

**The release gate is the live arc — and it carries three evidence obligations, not one.** A green leg that never exercised the contested surface is not proof, and each residual fails green in its own way:

1. **R-2 is invisible to storage.** R-1 re-attributes the relayed turns at close, so a correct-looking `episodes` table is consistent with the tenant having been dropped on every hop in between. The wire is the only instrument: Leg 2's **per-dispatch `principal.id` table**, verbatim.
2. **R-1 + ISSUE-0131 need the triple, not the pair.** A room with one `local` principal and three agent speakers yields *one* row under the principal axis alone and **three** under the record key — so the report carries `(principal_id, speaker_id, summary)` **triples**, and the count is the assertion.
3. **Idempotence is an absence bar, and an absence bar is satisfied by any empty recall** — a write that never landed, a fetch that returned nothing, an interaction that never closed. Leg 9 therefore reads **both partitions' row counts across the restart**, not just "no growth": the first restart after live traffic derives that window **once**; every restart after it with no traffic between is flat.

**Out of scope**: new feature work. The v0.4.0 on-ramp (RFC 0038 §C–§E, RFC 0049 Phases 2–4, RFC 0039 Phase 3, RFC 0040 Phases 2–4, RFC 0041 Phase 1) stays parked, as does the [v0.3.16 bundle](v0.3.15-plan.md#scope-decisions-locked-at-plan-opening-2026-08-23). The capacity sweeps and the two issues filed during implementation ([ISSUE-0137](issues/ISSUE-0137-episode-write-boundary-cannot-express-the-records-principal.md), [ISSUE-0138](issues/ISSUE-0138-close-reserve-multiplier-calibration.md)) are **Known Gaps to state**, not work to do.

**Documentation timing policy** (carry-forward): public docs updated *before* tag; post-tag-only artifacts (tag link, release URLs, "Released" stamps) → [Phase 4](v0.3.15-plan.md#phase-4--tag-and-post-release-follow-up).

## Track B — Release Engineering

### PR 3 — Version Bump + Changelog Curation & Dating

**Branch**: `feature/v0315-release-prep-version-bump`

Scope: bump `0.3.14` → `0.3.15` ([`bump_version.py`](../scripts/bump_version.py) + `cargo update --workspace`); `make all` + `make ui`; curate `[Unreleased]` → dated `[0.3.15]`; write the **Upgrade Notes**, whose obligations are fixed here:

1. **Four store migrations across two databases** — named with their stores, forward-only, the v13 repair stated as a repair. The release's one non-drop-in property.
2. **The coherence trade.** Close-derived group memory now fragments per speaker per tenant; room continuity is untouched — the promise applied inside a room, not a regression.
3. **The reserve re-size and its clamp consequence.** `R` grows with the cube of the room, so the half-cap clamp now bites in ordinary configs — bounded (the discussion gets half its budget; the close fires earlier, never later) and **no longer silent**: `channel.conversation.synthesis_reserve_clamped`.
4. **The `agent.interactions.closed.by_<reason>` metric shape change** — dashboards keying off it need re-checking.
5. **The narrowed catch-up skip** — a replayed span derives under its own tenant instead of being skipped wholesale, and derives **once** across restarts.
6. **`auth.mode: disabled` is byte-identical on the principal axis** — deliberately not on the speaker axis.

Acceptance: all version strings at `0.3.15`; curated dated `[0.3.15]`; prior sections untouched.
