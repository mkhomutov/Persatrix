## MT-PERSONA-RECALL-001 — Verbatim recall scoped to presence (live)

**Channel**: `group:mt-recall-001`. **Verdict: ⏳ Pending live Docker run.**

The deterministic half of this MT (the store- and endpoint-level scope, the gap-exclusion, the audit-count-not-content, the two-stint history, the epoch hard-filter, the session-span) is **pinned green** by the structural gates above (`TestRecallMessages_Scope_JoinLeaveRejoin`, `TestRecallEndpoint_JoinLeaveRejoin_BothStintsGapExcluded`, `_EmitsAuditEvent_CountNotContent`, `TestGetMembershipIntervals_TwoStintHistory`). What remains for the **live** run is what automation cannot prove: whether a **real persona**, given `recall_channel_messages`, reaches for it to quote a prior message and is held to the same closure-bound scope (Step 5), end-to-end on a running stack.

These are recorded as deterministic-only rather than faked through the publish path.
