## Follow-ups

- **F-1 — Stale "consume LLM tokens continuously" cost-warning fires for `timers: []` personas** (new this run; severity: **low — cosmetic, not a regression**). ember-owl logs `WARN COST: …will consume LLM tokens continuously` at startup even with `autonomy.timers: []`, contradicting the idle-truly-idle promise it sits beside (the live 60 s window proved zero consumption). Predates RFC 0024; accurate only when timers / `tick_interval_seconds` are configured. Fix: gate the warning on a non-empty timer set. Worth a tracked-issue / RFC-0024-closeout bullet.
- **F-2 — Live `idle_reason=budget_denied` not observable on a stock persona (Edge Case 2 dominates)** (MT-COST-004 ⚠️; carry-forward of v0.3.2 [F-2]; severity: low). `test_tick_budget_denied_idle.py` confirms `idle_reason=budget_denied`. Live, every `legacy_tick` wake hit the RFC 0017 §F empty-context short-circuit first (`empty_context_tick`), masking `budget_denied` — identical to v0.3.2 (the §F guard stays load-bearing through Phase 5). A future MT needs a fixture that forces the LLM-call branch under budget pressure.
- **F-3 — Operator note: empty shell `ANTHROPIC_API_KEY` shadows `.env` under Compose** (carry-forward of v0.3.2 F-4; severity: low). See [§ Environment](#environment). Worth a one-line note in the release checklist environment-setup section (release-prep PR 2).
- **F-4 — Human chat peer recorded as `other_participant_type='agent'`, not `'user'`** (ISSUE-0068; found in the post-run MT-CHAT-004 dry-run; severity: medium; **pre-existing, not a v0.3.3 regression**). REST chat reaches the agent as a `ChannelMessageEvent` with no field for `participant_type`, so the agent defaults the peer to `'agent'` (reproduces with/without an explicit `participant_type='user'`). The relationship tier thus can't distinguish human-user from agent peers for chat. Fix needs peer type on the proto (RFC-gated) or registry derivation. Tracked in ISSUE-0068 / PR [#417](https://github.com/mkhomutov/Persatrix/pull/417). Does not affect the MT-IDLE-001 gate or the release decision.

## Notes

- The stack was rebuilt because the prior containers predated PR 4/5/5.1 code; a result against stale images would not represent the RC tip. The temporary `tick_interval_seconds: 10` edit (MT-COST-004 legacy-tick check) was reverted via `git checkout`, re-validated, and ember-owl restarted back to `timers: []` — `git diff` clean.
