## Findings & follow-ups

| # | Severity | Finding | Disposition |
|---|----------|---------|-------------|
| F-1 | **high** | **The containerised orchestrator could not be built at the RC tip.** Dependabot's x/crypto bump ([#877](https://github.com/mkhomutov/Persatrix/pull/877)) raised `go.mod` to `go 1.26.0` while `Dockerfile.orchestrator` still built on `golang:1.25-alpine` (`GOTOOLCHAIN=local`), so `go mod download` refused — `go.mod requires go >= 1.26.0` — and **every `make demo-*` stack was unbootable**. CI never sees it: the workflows read `go-version-file: go.mod` and no job builds the image (the same blind spot the offline-smoke gate exists to cover; v0.3.12's F-2 was the same shape one flag over). | **Fixed in this PR** — base image → `golang:1.26-alpine`; TDD: `tests/unit/python/test_dockerfile_go_toolchain.py` pins the builder tag against the directive (red before the fix). The arc ran on the rebuilt image. |
| F-2 | **high** | **The §F recall filter is audience-blind.** On the 5d turn the injection gate withheld both DM-taught facts (*withhold-disjoint*, nothing injected) and the model's `recall_channel_messages` round returned Alice's DM transcript to a `planning` turn — the handler binds the acting classification and the membership filter, not the acting room's members. The reply repeated the fact in front of Bob. Under `enabled` the same tool 401s (ISSUE-0140), which is the only reason that run's reply held. Not a regression — until v0.3.16 the injection path leaked the same fact, so the side door was moot; now it is the remaining path. | **[ISSUE-0158](../issues/ISSUE-0158-recall-filter-audience-blind.md) filed (high).** Release-blocking by the [plan's rule](../v0.3.16-release-prep-plan.md#pr-1--manual-test-execution-report); **maintainer call**: in-release fix (thread the acting channel id into the recall request; server-side member-subset check, the §D comparison) or a stated Known Gap in the release note. |
| F-3 | medium | **Episodic recall's score inverts BM25.** `1/(1+|rank|) >= 0.20` admits `|rank| <= 4` only; FTS5's rank grows with the match, so `zephyr` scores 1.0 and the episode's own summary as the stimulus scores 0.04 and is dropped (measured on the live store). The sanitised stimulus is the MATCH string — an implicit AND over every term.
