Three release-blocking issues are bundled in this PR alongside the execution report, following the [v0.2.3 precedent](v0.2.3-execution-report.md#release-prep-regressions-fixed).

| # | Area | Fix | Why it blocked the gate |

| 1 | Build / cross-platform | New [`.gitattributes`](../../.gitattributes) — `tests/fixtures/**`, `agents/security_patterns.py`, `agents/security_enums.py` pinned `eol=lf` | Windows checkouts with `core.autocrlf=true` rewrote the files to CRLF, breaking byte-for-byte parity tests: `TestContextPackage_FixtureMatchesCurrentWireShape` (RFC 0008 PR 6a, [#227](https://github.com/mkhomutov/Persatrix/pull/227)) and `test_pattern_parity::TestParityFreshness`. |

The in-process cascade synthesized events without policy/mentions, so the gate silently suppressed every cascade hop. Surface: `test_persona_e2e_grpc_events.py::TestCrossAgentRouting` failed (`call_count == 0`). |
| 3 | Tests | [`tests/unit/python/test_action_executor.py`](../../tests/unit/python/test_action_executor.py) — two stale assertions updated | Two tests had been passing only because the gate was suppressing recipient responses; #2 above unblocked the cascade, surfacing them.
