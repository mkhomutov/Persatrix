### Integration Test Fix

`TestTickSchedulerIntegration::test_tick_fires_and_stops` was asserting
`create_message.call_count >= 1` — a check that became invalid after RFC 0017 §F introduced the
empty-context TICK short-circuit. A fresh agent with no memory now correctly returns `DO_NOTHING`
without invoking the LLM, so the scheduler's `idle_count` is the correct signal. The assertion
was updated to `scheduler.idle_count >= 1`.
