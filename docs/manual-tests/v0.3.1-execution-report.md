## Scope

This report executes the **30-test v0.3.1 surface** per [v0.3.1 release-prep plan PR 1](../v0.3.1-release-prep-plan.md#pr-1--manual-test-execution-report-v031-surface):

- **3 primary gates** for the v0.3.1 user-facing surface:
  - [`MT-SESSION-001`](MT-SESSION-001.md) — **new** — `PERSATRIX_SESSION_ID` cross-process write contract (RFC 0031 Phase 1).
  - [`MT-PERSONA-CONVERSATION-001`](MT-PERSONA-CONVERSATION-001.md) — **new** — persona conversational continuity over a DM channel (RFC 0034 Phase 1).
  - [`MT-MEMORY-005`](MT-MEMORY-005-dementia-test.md) — the dementia test, **promoted** from a v0.3.0 baseline measurement to a **pass/fail acceptance gate** (RFC 0026).
- **27 carried-forward** v0.3.0 regression tests (21 v0.2.x carry-forward + 6 channel MTs), regression-checking the v0.3.0 surface under the new facts-tier, session-column, and conversation-window code paths.

Per the [v0.3.1 release-prep plan](../v0.3.1-release-prep-plan.md#manual-test-state) the carried-forward inventory is **28 tests** (the 27 listed here plus `MT-MEMORY-005`); with the 2 new MTs the total v0.3.1 execution is **30 tests**.

### Release gate

- Every row reaches ✅ Pass or ⚠️ Accepted-with-known-gap; **zero ❌ Fail; zero ⬜ Pending**.
- `MT-MEMORY-005` Legs 1, 2, 5 record ✅ Pass with per-leg evidence (persona-prompt assembly trace showing the recalled fact / prior turn). A ❌ Fail on Leg 1, 2, or 5 is a **release blocker**.
- `MT-SESSION-001` asserts the **write-path contract only** — a row surfacing across sessions at *recall* time is **not** a failure (RFC 0031 Phase 2 work); note it explicitly so it is not mis-triaged.
- `MT-PERSONA-CONVERSATION-001` is **DM-only** — a group-channel failure is expected (RFC 0034 Phase 2) and is not a v0.3.1 regression.
- Every ⚠️ Accepted-with-known-gap row links a tracked issue or an RFC-closeout follow-up bullet.
- On a green run, the `MT-PERSONA-CONVERSATION-001` and `MT-MEMORY-005` source docs are promoted from `Draft (scaffold)` to `Active` (RFCs 0034 / 0026 landed).
