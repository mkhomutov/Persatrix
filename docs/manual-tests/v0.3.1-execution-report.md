## Execution constraint (resolved)

The prior pass was blocked because the repo `.env` carried `ANTHROPIC_API_KEY` with an empty value and `docker compose` aborted before any container started. That is **resolved**: `.env` now carries a non-empty key.

One environment subtlety surfaced and is worth recording for the release checklist: the test host's **shell environment** had `ANTHROPIC_API_KEY` set to an *empty string*, which (by Docker Compose precedence) overrides the `.env` file value. Every `docker compose` invocation in this run was prefixed with `unset ANTHROPIC_API_KEY` so Compose falls back to the `.env` file. Operators who export an empty `ANTHROPIC_API_KEY` in their profile will see the original `required variable ANTHROPIC_API_KEY is missing a value` abort even with a populated `.env` — unset the shell variable or give it the real value.

This pass executed the full live manual surface: the Docker Compose stack (orchestrator + 6 agents + Jaeger + Prometheus + Loki + OTel Collector), every live-LLM MT, and the `MT-MEMORY-005` dementia test with its two ≥ 11-minute idle gaps.
