## Running long commands

The full Python unit suite (`pytest tests/unit/python/`) takes ~5.5 min — run
it in the foreground with an explicit ≥10-min timeout. Don't run long commands
with guessed defaults, and don't pipe them through `tail`/buffering filters
when you need to detect completion: output stays empty until the run ends, so
a killed run looks identical to a live one.

Use the repo's `.venv` Python for Python gates (`make … PYTHON=.venv/bin/python`,
or `.venv/bin/python scripts/…`); the system `python3` lacks the dev
dependencies. Proto regeneration must use the CI-pinned toolchain (protoc
34.1, protoc-gen-go 1.36.11, protoc-gen-go-grpc 1.6.1) — newer local tools
produce stubs that fail the staleness gate.

Detailed test invocations: `go test ./internal/planner -v -run TestName`,
`.venv/bin/python -m pytest tests/unit/python/test_agents.py::test_name -v`.
`make proto-check` is the CI gate for Python stubs in sync + no orphans
(ISSUE-0023).

## Before and after every task

Verify the current branch (`git branch --show-current`) — a concurrent
session may have switched it. Then status hygiene per
[ROADMAP §How to Update](ROADMAP.md#how-to-update-this-file); keep the
ROADMAP header's latest-changes note short.

## Working in this repository

- **Review before merge.** Every PR is reviewed, findings are numbered
  `F-n` and each takes one of four dispositions —
  [review process](docs/methodology/review-process.md).
- **Local-only files are never referenced** in committed files; paraphrase
  the finding instead ([the paraphrase rule](docs/methodology/review-process.md#the-paraphrase-rule)).
- **Size caps**: code ≤ 500 lines, docs ≤ 3 000 words (RFCs 8 000); split at
  ~485 lines / 2 900 words, never trim. Measure words with the checker, not
  `wc -w` ([how](docs/documentation-guide.md#size-limits)).
- **FILEMAP.md** is regenerated by the pre-commit hook from tracked files —
  `git add` new files before committing so it sees them.
- **Version-train gate**: work slotted for a later version does not merge
  while the current release is uncut, even when asked; flag the sequencing.
